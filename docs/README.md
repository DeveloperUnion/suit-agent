# docs

クライアントから提供された資料と、社内で作成した打ち合わせ用の文書は
**このリポジトリに含めていない**。`private/` に置き、`.gitignore` で除外している。

| ファイル | 内容 |
|---|---|
| `private/採寸データ.jpg` | 実物の採寸票。**顧客の氏名と身体寸法が写っているため、リポジトリに入れない** |
| `private/要件定義書.md` | 要件定義書（ER図・画面構成・開発フェーズ） |
| `private/ヒアリングリスト.md` | 次回ヒアリングの質問リスト |
| `private/logo.png` | ロゴの原本。アプリが使う複製は `public/logo.png` |

`lib/constants/` のマスタ（採寸項目・補正コード・仕様の選択肢）と
`lib/types/index.ts` のコメントは `private/採寸データ.jpg` を参照している。
手元に無い場合は、コードのコメントに転記の根拠と判読が不確かな箇所を残してあるので、
そちらを参照すること。
